# DSLwFermi Triangular Lattice Generator

This folder contains a translation-only triangular-lattice TOML generator for xdiag.

## What it does

- Uses triangular primitive vectors with equal `y` and opposite `x`:
  - `a1 = ( 1/2, sqrt(3)/2)`
  - `a2 = (-1/2, sqrt(3)/2)`
- Builds torus sites from `(a, b)` using the same torus matrix convention as existing `genlat` scripts.
- Uses the translation subgroup generated by:
  - `Translation_a1` for `(1,0)`
  - `Translation_2a2` for `(0,2)`
- Writes NN (`J1`) and unique NNN (`J2`) `SdotS` interactions.
- Writes irreps as `[k1]...[kN]` with `characters` and `momentum` only.

## Files

- `genlat_triangular_tonly.py` - main generator
- `test_genlat_triangular_tonly_smoke.py` - smoke test
- `requirements.txt` - Python dependency list

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 genlat_triangular_tonly.py 4 2 --verify --toml triangular.12.a1_2a2.toml
```

## Run smoke test

```bash
python3 test_genlat_triangular_tonly_smoke.py
```
